# Security policy

## Reporting a vulnerability

Please report it privately: open the [Security tab](https://github.com/paulakarhi/FrameHeat/security) and choose
**Report a vulnerability**. Do not describe it in a public issue.

## Supported versions

Only the latest release gets fixes.

## Good to know

FrameHeat runs with administrator rights and installs the PawnIO driver, which is how it reads CPU and memory
temperatures. The README describes what that means for the folder it is installed in (see Limitations) and what the
program stores (see Privacy).
